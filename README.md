# 国际站的工作台

本包是本地工作台的源码备份，包含当前应用与顶层测试。它不包含现有业务数据、浏览器登录资料或完整的公司业务环境。

## 本地启动

Windows / Python 3.11+。在 workbench 目录运行 `python -B serve.py`，访问 http://127.0.0.1:8796/ 。启动前需配置本机依赖与业务能力；本包未在全新电脑完成部署验收。不要在服务器直接按本地配置对外开放。

- 原上品Skill、图片Skill、询盘Skill、经营面板引擎和商品诊断引擎分别在授权环境内安装、审核并配置；本包不分发这些私有/第三方资料。
- `WORKBENCH_ATTRIBUTE_SKILL_ROOT` 指向已审核的原上品Skill；`WORKBENCH_B2B_SKILL_ROOT` 指向生图Skill；`WORKBENCH_NODE_MODULES` 指向既有依赖目录。
- `WORKBENCH_STORE_YOUHEALTH_ID`、`WORKBENCH_STORE_LIFEWORTHCN_ID` 由部署者本地配置。本包已移除真实店铺身份ID，默认留空，未绑定时不能执行真实店铺业务。
- `WORKBENCH_SHARED_ROOT` 指定本机授权共享目录；原内网共享路径已从备份中移除。
- 本机路径、桥接运行时、模型执行器、Skill和外部数据源仍需按各模块配置。上传源码不等于云端可运行、平台报名通过或正式部署。

## 当前验收范围

已真实验收原Skill普通属性、10行自定义属性、8FAQ、5卖点、公司介绍及已有草稿回读；原Skill54项检查通过。相关专项代码测试31项Python、36项Node通过。

征品资格检测仍有4项业务缺口：可交易品能力、最小起订量、图片相似度、发货期。不能把代码备份标记为征品全链路验收完成。具体业务记录留在本地，未进入本包。

## 上传范围

仅上传解压后的本目录。建议先使用私有仓库。未包含：聊天归档、.state、数据库、API密钥、Cookie、浏览器profile、客户报告、截图预览、旧工程/迁移备份、审查沙箱、vendor、便携运行环境和node_modules。

程序化凭据模式检查未发现明显密钥；这不等于正式安全审计。本仓库仅保存源码，真实业务数据与登录资料留在本地环境。
