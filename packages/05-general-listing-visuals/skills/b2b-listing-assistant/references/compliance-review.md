# 证据与一致性审查

在生成前和交接前分别读取本规则。先检查商品身份、公司角色和可证明能力，再检查产品规格、文案、交易与图片是否同SKU同版本。适用规则随产品和页面变化，需要时查当前权威来源，不内置某行业具体资质或承诺。

每个可对外表达的事实记录：内容、来源、持有人／适用主体、产品范围、有效期或确认日期、可展示权限。公司级证明不自动适用于所有商品；参考图、竞品文案或搜索词不构成本公司产品证据。

风险输出逐项写明：原表述、证据缺口、影响模块、可采取的处理。没有证据时删除该主张或标为待确认；不要静默改变真实产品信息。没有工厂、认证、客户或评价不影响其他模块，但对应展示不能启用。

同时核对标题、属性、卖点、FAQ、主图、详情图、交易和物流。重复出现的同一值必须来自同一确认来源，冲突不能由某子模块自己决定。关键事实、页面必填或未知规则无法核实则阻断相应环节，并由主控集中反馈。

本参考文件规定Agent审查方法，不是法律意见、完整禁词数据库或已执行的自动扫描器。
