# 图片交接的三个关口

第一关是文件：当前SKU独立成品目录，名称、顺序、扩展名、解码和哈希明确。草稿、原图与其他SKU不能混入，未知文件不能静默跳过。

第二关是内容与页面：实际查看是否同款、文字和参数准确、无未授权素材；同时核实当前图片数量、尺寸、体积和详情模块。文件名和哈希不能证明图片内容，页面模块不能用历史数字ID推断。

第三关是真实上传结果：在获授权及工具可用时实际上传，回读缩略图、数量、分组顺序及错误；保存后重开核验。部分失败必须报告，不把已尝试或等待结束当成功。正式发布另按明确授权。

当前本地脚本仅覆盖第一关的部分检查，其他关口需要Agent与用户或现场适配。本文件不提供可运行的通用上传程序。
