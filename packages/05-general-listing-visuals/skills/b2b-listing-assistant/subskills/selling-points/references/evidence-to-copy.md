# 卖点子模块：从事实到采购信息

主控提供同SKU产品资料、适用公司能力、当前页面格式与数量限制，以及选填参考稿。先按买家需要组织产品身份、规格差异、可核实质量依据、适用条件与合作服务；哪些主题有证据就写哪些，不要求每家公司都具备全套能力。

建立逐条对应：草稿表述 → 支持事实 → source → 主体／SKU范围 → 缺证据或冲突 → 能否使用。公司工厂、产能、认证、客户和检测等只在证据真实且适用时写。没有依据的主题关闭，不拿另一SKU或合作方的事实填空。

卖点应补充决策信息而非重复标题或堆关键词。条数、编辑器格式及总字数依据当前页面，而不是旧行业的固定数字。输出草稿、来源表和未解决项；用户确认前不视为可填写成品。

与FAQ和图片同源：子模块不能各自产生不同MOQ、交期、包装或能力数字。本文件是Agent规则，无自动生成或平台填写实现。
