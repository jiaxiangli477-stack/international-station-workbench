# 通用卖点子模块

主控提供已确认产品资料、公司能力、真实页面字段限制及选填参考稿。本模块不要求用户先写好卖点，不重复索取已有资料。

原包的卖点模块负责 manifest.selling_points。保留从产品身份、可证明差异、质量依据到采购服务的组织思路；按当前类目和页面要求决定条数、格式和字符限制，不把原行业的固定参数视为所有类目要求。

从SKU事实和适用公司能力提炼买家决策需要的信息，避免标题重复和关键词堆砌。贸易公司按真实角色表达，不强制融合自有工厂、研发、认证、测试、客户或产能；没有这些证据就省略对应表述。旧稿及竞品材料仅作表达参考。

逐条列出卖点与来源对应关系，核对与标题、属性、包装及交易资料的一致性。输出英文草稿、来源、待确认项与风险，供用户复核；无法支持的表述不生成。需要页面填写时由主控按授权操作、回读核验。本子模块为Agent工作指令，尚未移植原包的自动生成脚本。
