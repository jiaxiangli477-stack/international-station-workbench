# 标题子模块：输入、生成、审查与交接

输入由主控提供：确认的产品身份、类目适用规格、确认品牌（如有）、真实页面字符限制、选填旧标题／关键词／禁用词。缺旧稿不阻断，缺产品身份不硬编。

生成候选时先回答产品是什么，选择足以帮助买家识别的事实；参数、用途、材质或结构仅在适用于当前类目且有证据时使用。不套原行业词表，不用认证或服务承诺凑长度，不复制竞品。建议关键词与真实属性不一致时以事实为准。

每条候选交接text、字符数、使用的事实与source、待确认项、风险和推荐理由。候选状态为draft，用户复核后才可进入字段计划；当前页面限制未核实时不能标字符审查通过。候选间要有表达差异，但不为差异而新增事实。

最终检查：与属性、图片、包装的身份和规格一致；品牌写法有授权；字符上限来自当前页面。生成与清洗由Agent执行，本包未迁移原自动生成器。
