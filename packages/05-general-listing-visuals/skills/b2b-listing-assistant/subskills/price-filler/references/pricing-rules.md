# 交易规则与资料边界

数据来源：当前产品适用的报价、数量阶梯、MOQ、币种、计价单位、规格和报价条件，经使用者确认后才进入计划。资料有版本或产品范围差异时先保留冲突。旧报价、同类商品和竞品只能帮助提出问题，不能自动给本产品定价。

脚本处理min_quantity为正整数、unit_price为正且有限的十进制数值或字符串。只做结构校验，不验证实际币种资格、商业合理性、税费或平台可接受范围；不能自行换汇、折扣或推导遗漏价格。

阶梯数量需递增且不重复。首档数量与MOQ可以表达不同的业务概念，因此不强制改成一致，但不同就输出复核提醒。数量增加而单价升高也只提醒，由业务确认实际条件。

本地计划只供主控与用户复核。页面可能采用不同销售方式、区间、单位或规格组合，需读取当前交易区证据后适配。保存与正式发布遵循用户对外部操作的具体授权。
