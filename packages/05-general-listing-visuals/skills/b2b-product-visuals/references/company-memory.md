# 新资料在使用后形成，不随空白包分发

初始通用包不附公司名、品牌、产品、具体类目、业务参数、资质、厂房、客户或演练图片。

用户提供并确认的必要资料，由Agent通过宿主文件工具写到其授权环境中当前Skill的references/companies/<公司标识>/，按实际需要保存公司／品牌事实、视觉要求、来源与授权、产品索引及具体产品记录。没有品牌需求的无品牌图不强求公司信息。

原始图片可以留在用户提供的产品库，记录授权路径即可；不把整库复制进公开Skill。不同公司与产品独立映射，记录版本和未确认项，不能继承其他主体的照片、参数或能力。若与上品Skill共用同主体资料，核对来源和版本，不另问重复问题。

填写工作区保持原资料；Agent给统一摘要，经用户确认后才形成参考事实。不要求用户自己编写Markdown。资料变化时先核对差异与确认范围再更新，不把设计建议写成已有品牌规范。

分享、打包或上传此通用Skill时，只带SKILL、通用references和空白模板；排除所有真实companies、产品索引、图片库、outputs、公司专属配置以及凭据／客户隐私。本包不含执行存档的Python或其他脚本。
