把资料放进来，统一交给 Skill

阿里巴巴国际站 · 上品与商品图片 · 公司首次配置

  1. 把资料包文件夹改成公司名。
  2. 将已有文件放入对应目录；每个目录都有说明。
  3. 多个类目或产品，复制对应的示例文件夹再改名。
  4. 在根目录的“资料状态与待补说明”里注明缺少、不适用和不能公开的内容。
  5. 提供整个资料包或本地授权路径，由 Agent 统一读取与反馈。

各目录放什么

  • 01-公司介绍与业务能力
  • 02-类目发布页
  • 03-产品资料
  • 04-品牌与视觉规范
  • 05-按需展示的真实素材
  • 06-FAQ与风格参考
  • 99-其他现成资料
  • 07-标题关键词与文案参考-选填

必备与选填

基础资料用于确认公司、产品和页面结构；具体必填数据按真实页面补齐。已有标题、关键词、文案与风格参考均为选填，没有时由AI依据确认资料生成草稿。证书、工厂和客户案例没有证据就不启用相应展示模块。详见根目录“00-必备与选填说明.txt”。

截图怎么准备

选好具体类目后保留发布页 URL 和类目路径。展开其他属性，分段拍清字段、必填标记、单位；下拉展开，搜索型下拉再搜索本产品对应值。交易、物流及详情区域按实际页面提供。能由 Agent 直接读取当前页面时，无需重复截图。

你不用重新填写专业表格

现成 Word、PDF、Excel、图片或链接都可以。多款产品分别标明对应关系；不能拆开的资料可以放“99-其他现成资料”。先做一款代表产品也可以。

没有资质、工厂图、客户案例或品牌规范，可以注明；目录不是全员必填清单。不得编造参数或素材。已填写的公司资料包可能含内部信息，分享范围需要自己确认，不提供账号凭据或客户隐私。

提交后会怎样

Agent 先读取全部资料，再核实发布页字段与选项，将产品资料逐项对应，统一列出缺项、冲突和不适用模块。你确认摘要后，才写入 Skill 的公司专属参考资料。实际制作、页面填写和发布结果另行验证。
