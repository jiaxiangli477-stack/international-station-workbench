# 通用规则的检查范围

三个独立subagent进行了本地资料流程、图片交接与整体可执行性审查。发现的问题经主代理修复后再次复审；已有28项本地测试和3步隔离演练记录。

通用包仅包含规则、空白模板及本地脚本，不附演练公司、演练产品、演练类目、测试图片、原始审查夹具或真实业务参考库。详细历史验证记录独立保存在授权本地验证目录，未进入此公开包。

已检查的本地机制包括来源标记类型、SKU绑定、冲突处理、CSV内容转义、空白及非有限值、页面字段计划、必填与可选、已观察选项、支持的字段限制、图片命名、顺序、模块映射、解码与格式等。

这些检查不证明原始材料真实、图片内容属于该产品或平台实际已操作。真实国际站填写、上传、草稿保存与回读未完成通用适配和现场验收；完整视觉模板和批量制作也未完成迁移。实际功能范围以各Skill及思路说明为准。
