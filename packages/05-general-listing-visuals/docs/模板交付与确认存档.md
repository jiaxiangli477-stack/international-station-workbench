# 模板交付与确认存档

首次／新公司／无有效配置时，Agent按上品SKILL入口实际运行init_workspace.py，直接提供生成的填写目录、ZIP和说明链接。使用者填写TXT、放已有资料并保存副本，再交整个目录／ZIP或授权路径。母版保持空白，已有副本不覆盖。

Agent实际读取并集中核对，用户确认摘要后组织内部确认数据，再运行save_profile.py写入当前Skill的references/companies/<公司标识>/并读回。填写保存的是原材料，确认入库的是可复用参考，两者不混同。用户不需要自己写JSON。

具体输入和更新边界见上品references/template-delivery.md；已有同公司配置先复用，更新先核对差异与确认。模板交付／存档已本地验证，平台保存商品另需真实页面验证。
