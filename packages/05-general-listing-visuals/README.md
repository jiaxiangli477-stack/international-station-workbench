## 一次准备，统一整理

使用者按模板提供类目、选类目后的发布页 URL 与截图、公司介绍、产品规格和实拍、交易物流及品牌素材。已有标题、关键词、参考文案等选填；没有的展示资料不编造。Agent先读全部资料和页面字段，再集中反馈缺项或冲突；摘要确认后写入公司专属参考目录，不跨公司或SKU混用。

## 当前实际能力

- Agent工作流程、公司资料配置、标题/卖点候选规则。
- prepare.py基础复核，build_plan.py本地字段计划校验，image_inventory.py成品文件与模块清单检查。
- render.py真实照片中性预览，仅基础排版。
- 三个subagent完成独立本地审查及修复后复审；28项本地测试、3步虚构CLI演练通过。详见[检查摘要](docs/Subagent实验检查与修复报告.md)。

**尚未完成**：完整通用浏览器填表、上传、草稿保存与回读执行器，以及原视觉包完整模板和批量制作迁移。未验收真实国际站上架，不能把本地ready状态视为已上传或可发布。

## 文件命名

单款产品的确认成品放在 `主图/m1.png…m6.png` 与 `详情页/d1.png…`，详情通过 `detail-map.json`明确当前页面模块及整数顺序；不凑满图量，尺寸与数量需核对实际页面。[详见交接规范](docs/主图详情图命名与交接.md)。

## 分享与更新

公开包只带空白模板和通用源码，不含真实公司专属参考、账号信息或原始审查夹具。公司实际资料写入后应保留在授权本地环境，勿直接提交公开仓库。本目录与 `workbench/` 及之前的原始分发包独立，不宣称已经接入其运行环境。

## 空白通用包

公司、品牌、产品、报价、资质、工厂、客户与具体类目事实均不预填；字段名、目录占位符和技术约束属于结构规则。使用者确认资料后才在自己的授权环境形成专属配置。包内不附原始演练或审查夹具。
